# Sandwich Leads MVP

Агрегатор заявок на строительство из сэндвич-панелей.

## Назначение MVP

Лидогенерационный агрегатор, который проверяет две гипотезы:

- **H1 (спрос):** пользователи готовы проходить калькулятор, получать
  предварительную оценку стоимости и оставлять контакты.
- **H2 (монетизация):** производители сэндвич-панелей готовы платить за
  квалифицированные лиды, и один лид можно продать нескольким поставщикам.

Регион теста: Москва и Московская область.

Проект не является магазином, каталогом, маркетплейсом, строительной
компанией или сервисом онлайн-смет.

## Статус

**Текущая версия — только фундамент проекта (PROMPT 1).**

Реализовано:

- базовая структура Flask-приложения;
- маршруты `/`, `/privacy`, `/consent`, `/terms`;
- placeholder-шаблоны и статические файлы.

НЕ реализовано (следующие этапы):

- лендинг, калькулятор, Price Engine;
- контактная форма и Lead ID;
- интеграция с Google Sheets и Telegram;
- UTM и аналитика;
- рекламные входы `/garazh`, `/sto`, `/sklad`;
- подбор поставщиков, оплата, автоматизация.

## Стек

**Frontend:** HTML5, CSS3, Vanilla JavaScript
**Backend:** Python, Flask
**CRM (планируется):** Google Sheets
**Уведомления (планируется):** Telegram Bot API

## Требования

- Python 3.10+

## Установка

1. Создайте виртуальное окружение:

```bash
python3 -m venv venv
source venv/bin/activate      # macOS / Linux
venv\Scripts\activate         # Windows
```

2. Установите зависимости:

```bash
pip install -r requirements.txt
```

3. Скопируйте файл переменных окружения:

```bash
cp .env.example .env
```

На этом этапе реальные значения переменных не требуются — приложение
их пока не использует.

## Запуск

```bash
python app.py
```

Приложение будет доступно по адресу:

```
http://127.0.0.1:5000
```

Доступные маршруты:

- `/` — главная страница (заглушка будущего лендинга)
- `/privacy` — политика обработки персональных данных (placeholder)
- `/consent` — согласие на обработку персональных данных (placeholder)
- `/terms` — пользовательское соглашение (placeholder)

## Важно

Это только фундамент MVP. Юридические тексты — placeholder и будут
заменены реальными текстами отдельно. Функциональность калькулятора,
расчета стоимости, приема заявок и интеграций будет добавлена на
следующих этапах разработки.
